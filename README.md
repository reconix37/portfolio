# DANIIL OS — personal site

Персональный сайт Даниила Верховского — AI/ML engineer. Сайт играет роль персональной ОС: терминальный вход, окна-секции, маскот-агент, системные метаданные.

Вайб: нео-брутализм / old-web (референс KISA, Poolsuite). Никакого AI-слопа.

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS v4 + shadcn/ui
- Syne + Space Mono

## Dev

```bash
npm install
npm run dev
```

## Design system

`DESIGN.md` — токены, компоненты, антипаттерны. Токены уже в `src/index.css`.
`AGENTS.md` — правила и бриф для AI-агентов (Cursor).

## Content

Контент — реальный, из резюме (проекты HabitForge, AI Chat Platform, SLE Terminal, thesis). Только реальные метрики.
